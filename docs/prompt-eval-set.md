每批改动前后使用同一套输入和判分口径，保存必要的脱敏记录并附前后对比。批 0 建评测骨架和记录位；下表留空或标「待补」不代表已经执行。

**全局隐私规则：** 密码、密钥、验证码及其他认证值（例如 token、cookie、会话标识）不得写入评测表、日志、截图、仓库或共享产物。个人数据默认排除或脱敏；模型回复、样本、工具参数/返回、对话和提示词快照也只保留判分必需的最少非敏感事实。确需核对原始材料时，只记录脱敏后的证据位置；原始材料由醒醒留在其指定的受保护位置，不复制进仓库或共享记录。

### 执行步骤

1. 使用醒醒提供的固定任务输入；测试前先登记每个任务预期调用的工具及参数要求，避免看过模型输出后再改判分标准。

3. 单次调用只有在工具名正确、必需参数齐全且取值符合原任务要求时才计为「参数正确」；工具执行成功与否另记，不和参数正确混为一项。
4. 汇总：参数正确率 = 参数正确调用次数 ÷ 有效工具调用总次数。另记一次成功率 = 首次调用参数正确且工具执行成功的任务数 ÷ 已执行任务数。若没有调用或任务未执行，记「未测」，不以 0% 或 100% 代替。
