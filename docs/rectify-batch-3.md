## 本次改动

`AIChatViewModel+ToolDefinitions.swift` 加 13 行：
语音工具（send_voice / textToSpeech / text_to_speech）在开关关闭或没配 TTS 时从 schema 移除。

边界处理：sessionId 为 nil（会话未绑定）时不摘——此时开关读不出值，摘掉会把功能整个弄没，而派发层此时也不拦。

派发层的拦截保留作兜底：万一模型幻觉调用，它会收到「语音关了，别合成，如实告诉主人」，不会谎称发了。
